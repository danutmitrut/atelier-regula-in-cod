# Atelier: de la regulă în prompt la verificator în cod

Materialul atelierului Business Architect AI din 16 noiembrie 2026.

O flotă mică de agenți Claude Code (Copywriter, Designer, orchestrator) care scrie o postare de LinkedIn și un carusel după un brief. Regulile lor stau, la început, doar în prompt. În atelier muți o regulă în cod: scrii verificatorul, îl vezi picând, scoți regula din prompt și legi verificatorul de orchestrator, apoi vezi cum oprește o postare greșită.

Pașii, cu explicații și prompturi, sunt în [GHID.md](GHID.md).

Ai nevoie de Claude Code și de Python 3. Verificatoarele folosesc doar Python standard.
